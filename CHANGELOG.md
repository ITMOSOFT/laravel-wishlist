# Changelog

## [1.0.0] - 2026-11-10

### Added
- Customer and guest wishlists.
- Default wishlist creation and retrieval.
- Polymorphic wishlist items.
- Add, remove and move operations.
- Guest-to-customer wishlist merge.
- Wishlist lifecycle events.
- Configurable table prefixes.
- PHPUnit unit and feature tests.
- Laravel 12 and Laravel 13 GitHub Actions matrix.
